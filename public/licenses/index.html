Third-party licenses and asset sources

No license has been selected for the original application code. Public visibility does not grant a license. Each third-party component retains its own terms.

Assets are separate from package code

  • The TalkingHead MPFB avatar is CC0 according to its pinned asset-specific upstream declaration. The CC0 text accompanies it.
  • The Kokoro timestamped model and nine voice files match upstream SHA-256 identities. Their separate model card and voice model card declare Apache-2.0. The standard Apache-2.0 text accompanies them. No standalone upstream model repository LICENSE file was available.
  • The dictionary retains the Carnegie Mellon notice in its original header.
  • The modified vendored HeadTTS code retains its MIT license and modification notice.
  • Space Grotesk and IBM Plex Mono font texts appear under their @fontsource packages below. Their fonts retain OFL-1.1, not the application code terms.

The asset manifest records pinned URLs, revisions, exact file hashes, and the avatar preparation command. These records identify sources and declarations. They are not a blanket legal clearance of model training data, voice likeness, or every underlying right.
